## ما الذي تغيّر في 1.1.0؟

- توحيد سلوك التطبيع بين اللغات الثلاث وفق `SPEC_VERSION=1.0.1`.
- إصلاح تحويل الأرقام الفارسية إلى الأرقام العربية الشرقية عند الطلب الصريح.
- توضيح حفظ `ة` في مفتاح البحث الصارم، وتحويلها إلى `ه` في المفتاح المتساهل؛ تطبيق نوع المفتاح نفسه على الفهرس والاستعلام.
- تحسين توثيق قواعد البحث: الحفاظ على النص الأصلي، عدم خلط المفاتيح، وتجنب البحث الفارغ، مع فرار أحرف `LIKE`.
- إضافة اختبارات تغليف وتوافقية وإصلاح مشكلة في اختبارات Python 3.9.
- معالجة التحذيرات التي كانت موجودة في تبعيات التطوير عند مراجعة الإصدار؛ لا تمثل تلك النتيجة ضماناً أمنياً دائماً.

## الخطوات القادمة بعد إصدار 1.1.0

1. **تحديث واجهة GitHub العربية:** يُقدَّم تحديث `README.md` وهذه الوثيقة عبر فرع توثيق مستقل، ويُدمجان فقط بموافقة المالك وتحت قواعد حماية `master`؛ لا يجعل توثيق GitHub يعلن إصداراً غير منشور.
2. **توحيد التوثيق العام:** ربط توثيق السجلات الثلاثة بصفحات المستودع والمواصفة، مع المحافظة على أمثلة الصارم/الصارم والمتساهل/المتساهل وعدم تعديل الحزم المنشورة.
3. **تحسين أمان الإصدارات القادمة:** استخدام توقيع Git SSH للوسوم الجديدة، والنظر في Trusted Publishing / OIDC وقيود GitHub Actions؛ لا تُبدّل الوسم التاريخي غير الموقّع `arabic_text-v1.1.0`.
4. **اختبارات التكامل حسب الحاجة:** تجربة Supabase SDK وCloudflare Worker/native ESM في بيئات اختبار، دون تصوير هذه التحققات غير المنفذة على أنها منجزة.
5. **P1.0 — تطوير منفصل:** دراسة API قابلة للتخصيص لتطبيع البحث استناداً إلى RFC، مع موافقة تصميم وتنفيذ مستقلة.
6. **GitHub Release اختياري:** قرار نشره مستقل ولم يُعتمد حتى الآن؛ لا يلزم لإثبات نشر الإصدارات الثلاثة على سجلات الحزم.
